# PixelBoost

Simple browser upscaler for **images** and **videos**.

- Image: ESRGAN AI · 2x / 4x / 8x
- Video: Quality (fast) or AI frames · 2x / 4x · exports WebM

All processing stays on your device.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
